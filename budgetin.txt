# 💰 Budgentin - Financial Tracker App

## 📌 Project Overview
Budgentin adalah aplikasi untuk membantu user mencatat pemasukan dan pengeluaran secara mudah, baik melalui web maupun Telegram.

---

## 🎯 Objectives
- Tracking pemasukan & pengeluaran
- Monitoring keuangan harian & bulanan
- Input data via Telegram bot
- Dashboard analytics sederhana

---

## 🧱 Architecture

Menggunakan pendekatan microservices + container:

[Frontend (Next.js)]
        |
[Backend API]
        |
 ├── Auth Service
 ├── Transaction Service
 ├── Analytics Service
        |
   [PostgreSQL]
        |
 [Telegram Bot Service]

---

## ⚙️ Tech Stack

### Backend
- Node.js (NestJS / Express)

### Frontend
- Next.js
- Tailwind CSS

### Database
- PostgreSQL (utama)
- Redis (cache / session)

### DevOps
- Docker
- Docker Compose
- GitHub (version control)
- GitHub Actions (CI/CD)

### Integration
- Telegram Bot API

## 🐳 Docker Requirements

Semua service harus containerized:

- frontend
- backend
- database (PostgreSQL)
- redis
- telegram bot

---

## 🔄 CI/CD (GitHub Actions)

Pipeline:
1. Push code ke GitHub
2. Run test
3. Build Docker image
4. Push image ke registry
5. Deploy (optional)

## 📲 Telegram Bot

### Command Example:

### Flow:
1. User kirim command
2. Bot parsing data
3. Kirim ke backend API
4. Simpan ke database
